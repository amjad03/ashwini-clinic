# Ashwini Clinic — Website

Single-page marketing website for **Ashwini Clinic**, a medical centre in Doddanekkundi, Bengaluru, led by **Dr. Amareshayya Hosamata (BAMS)** — combining Ayurvedic wisdom with modern medicine.

Static site: plain HTML/CSS/JS, no build step.

## Structure
- `index.html` — the entire site (styles + scripts inlined)
- `assets/` — optimised doctor portraits and clinic photos

## Run locally
Any static server, e.g.:
```bash
npx serve .
# or
python3 -m http.server 4321
```
